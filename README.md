# 📊 Dashboard

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um Dashboard para visualização e acompanhamento de dados, utilizando informações armazenadas em uma planilha do Excel.

O objetivo é apresentar os dados de forma organizada, visual e intuitiva, facilitando a análise e a interpretação das informações.

## 🚀 Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Excel

## ⚙️ Funcionalidades

- Visualização de dados em gráficos.
- Apresentação de informações de forma organizada.
- Integração com uma planilha do Excel.
- Interface simples e intuitiva.

## 📂 Como executar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Verifique se a planilha do Excel está no local correto.
4. Abra o arquivo `index.html` utilizando o Live Server.
5. Acesse o Dashboard pelo navegador.
